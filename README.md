# liberacao_ifciencia
Este script em Python automatiza a emissão de autorizações oficiais de saída de sala de aula para alunos participantes de atividades do projeto IFCIÊNCIA PODCAST (IFMT - Campus Primavera do Leste). O programa compila os dados dos discentes em uma tabela estilizada e gera um PDF pronto para validação.

Objetivos do Projeto
Agilizar a dispensa formal de estudantes para gravações e monitorias do podcast.

Garantir a transparência do processo perante professores e servidores da instituição.

Apresentar a lista de alunos em uma tabela visualmente limpa e padronizada.

Tecnologias Utilizadas
Python 3.11: Linguagem principal para lógica e fluxo interativo.

ReportLab: Utilizado para construção do layout, aplicação de estilos (TableStyle, Paragraph, Spacer) e criação das tabelas.

Datetime: Utilizado para geração de data/hora dinâmicas nos nomes dos PDFs.

Pré-requisitos e Instalação
Certifique-se de ter o Python 3.8+ instalado.

Instale a biblioteca reportlab no seu ambiente:
  pip install reportlab


para usar basta executar o arquivo.py e seguir as instruções escritas em seu terminal; Ao finalizar, será gerado um pdf com as informações inseridas.
